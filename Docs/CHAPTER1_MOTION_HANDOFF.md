# Chapter 1 hit and grab adaptation

The C1 placeholder now uses a separate skinned silhouette with a ten-bone Generic rig. The original placeholder and Raka hero sources are preserved. Spine, chest, head, upper arms, forearms and hands are independently deformable.

`Hit_Chest` and `Hit_Final` adapt CC0 Quaternius/KinemIQ motion; `Grab_Player` is original. See `ThirdPartySources/QuaterniusMotion/README.md` for provenance. This change does not install the Raka hero model or implement Chapter 2.

Source: `BlenderSources/Characters/ACT_C1_ShadowMotion.blend`, generated by `adapt_chapter1_motion.py`. Export: `ACT_C1_ShadowMotion.fbx`. Prepared runtime prefab: `Assets/_NoRainbowAfter/Resources/C1ShadowMotion.prefab`.

`ShadowPlaceholderVisual` replaces the old rendered meshes with the prepared skin, retaining their materials. Encounter logic samples clips using its own clock, so pause/inspect and deterministic QA remain consistent. Regular hits play ~0.53 s, the third hit ~1.2 s. The third hit resolves only after its reaction. Grab follows the existing 1.15 s capture clock; escape and checkpoint rules remain unchanged.

To rebuild the prefab, run `NoRainbowAfter.Editor.ChapterOneMotionInstaller.Install` in Unity. When running the `RiggedHitAndGrabStayGroundedAndReset` PlayMode test, set `NRA_MOTION_CAPTURE` to an absolute output directory to capture the camera preview frame sequences. Camera captures omit overlay HUD/damage tint.
