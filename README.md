# No Rainbow After

Proyek game horor psikologis first person untuk Windows x64.

Buka dengan Unity **6000.6.8f1**. Pipeline yang saat ini terpasang adalah **URP 17.6.0**; target HDRP dalam GDD masih memerlukan keputusan terpisah.

Untuk menjalankan fondasi T01, buka `Assets/_NoRainbowAfter/Scenes/Boot.unity` lalu tekan Play. Coba Mulai Baru, Pengaturan, Kredit, dan Kembali ke Menu. MasterGameplay masih placeholder; controller dan gameplay belum dibuat.
